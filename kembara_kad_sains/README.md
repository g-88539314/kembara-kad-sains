# Kembara Kad Sains — Year 4

A static prototype of the Kembara Kad Sains educational game.

## Included
- Four uploaded Science Hero character images
- Student profile
- QR `?card=nafasio`, `?card=kumuhrion`, `?card=tinjatron`, `?card=impulso`
- Four 10-question quizzes
- 80% passing threshold
- +20 XP and +20 score once per completed mission
- Four-card collection
- Progress dashboard
- Responsive design

## Important
This first prototype stores progress in the browser's `localStorage`. It is intentionally a front-end prototype. A shared cloud database can be connected in the next phase so progress follows the student across devices.

## Run locally
Open `index.html` in a browser. For best results, use a simple local web server because relative assets are used.

## GitHub Pages
Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository's Pages settings.
